# Economics — honest prototype math

## Today (real numbers)

- Sara AI live at saraai.chat: **zero revenue**. Launched days ago, family-only, registration gate, no paywall.
- Cluster power: ~$50–$80/mo.
- OpenRouter: not listed yet.
- Public users: zero.

## The loop the grant funds

1. **Public tier** — once the installer + dashboard ship, open registration to a small external tier. 20 users × $10/mo = $200/mo.
2. **OpenRouter idle** — list endpoints; paid per token when the family isn't using the box. Marginal cost ≈ electricity.
3. **Video tier** (Phase 2) — 2–5× image margin per token.

## Break-even target

6–12 months after the public tier opens, faster with video. The grant buys the software and networking that make the loop possible.

## Why fund a zero-revenue prototype?

Foresight funds blueprints and prototypes, not proven businesses. A real working node with an honest gap and a documented path to self-sustain is more credible than inflated projections. This file says exactly that.
